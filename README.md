# YuriiNote

紙のPKM（ツェッテルカステン）をデジタルでやるアプリ。ノート・日記・チャットメモ・なりきりチャット・キャンバスを、1つのフォルダに平らに保存します。
方法: https://yurii7812.github.io/homepage/ja/paper-pkm/

## インストール（コマンド1行・リリース不要）
| OS | ターミナルに貼る |
|---|---|
| **Linux / macOS** | `curl -fsSL https://raw.githubusercontent.com/Yurii7812/YuriiNote/master/install/bootstrap.sh \| sh` |
| **Windows**（PowerShell） | `irm https://raw.githubusercontent.com/Yurii7812/YuriiNote/master/install/bootstrap.ps1 \| iex` |

GitHub からソースを取ってきて、その場で組み立てます（git と Node.js 18 以上が無ければ、自動で用意します。初回は数分）。デスクトップとアプリ一覧にショートカットができ、端末では `YuriiNote` で開きます。もう一度同じ1行を実行すると最新になります。インストーラー（AppImage / exe / dmg）を自分で作りたいときは `npm run dist:linux` など（`release/` にできます）。

## 更新（自動では何もしません）
確認も更新も、**自分で押したときだけ**。
- **コマンド1行で入れたとき（Linux / Mac / Windows）**: 端末で **`YuriiNote --update`**（確認だけなら `--check`、バージョンは `--version`）か、アプリの「⋯」→「更新を確認」。`git pull`・`npm install`・ビルドまで行います。更新したらアプリを開き直す
- AppImage / インストーラーで入れたとき（`npm run dist` で作ったもの）は、置き換え式の更新です

## リンク・展開・参照検索（1.1.0）

- 「＋新規」→「リンクを作成」で、ノート・紙ノート・チャットメモを検索して複数の参照先を束ねます。ノートの「⋯」、ノート／メモの複数選択、メモの右クリックからも作成できます。「リンク一覧」から再編集できます。
- `[名前](link:ID)` は通常リンク、`![名前](link:ID)` は本文を展開します。元のデータを複製せず、普通の本文と同じ文字・行間、細い左縦線で表示します。保存後の「通常ノートを作成」では、その展開リンクを持つ普通のテキストノートを作ります。
- 日付の新しい順が初期値です。日付の古い順・種別順に切り替えられ、手動で↑↓を動かしたときだけ指定順ができます。日時表示は展開の上部でON/OFFでき、初期はOFF。部分範囲・バックリンク・循環展開の保護にも対応します。
- 通常ノート／チャットメモで `:` から参照検索。**Enter＝前置、Shift+Enter＝後置**。Escは入力を残して検索だけを終了します。コード、URL、時刻、既存参照では起動を抑制します。過去の `@` を含む本文は書き換えません。
- 通常ノートの「⋯」から、チャットメモへのメンション／リプライも挿入できます。
- 単独行URLはコンパクトなサムネイル付きプレビュー、文章中のURLはテキストリンクです。「…」で各表示箇所のON/OFFを保存できます。既存URLも非同期で再取得・キャッシュし、設定から再取得の操作と進捗を確認できます。本文は変更しません。
- 一括トピック編集は**加算方式が初期値**で、既存の全員／一部の所属を表示します。書き換え方式を明示したときだけ置き換えます。入力欄の💬から下位トピックの作成へ進めます。

詳しい操作、記法、保存形式、参照検索の抑制、URL取得の制約は [リンクとプレビュー](docs/links-and-previews.md) を参照してください。

## 開発
`npm install`（初回のみ）→ `./yuriinote.sh`。試験は `npm test`。インストーラーは `npm run dist`（動かしている OS 用）。
**バージョンの付け方（1.x.y）**: 先頭は `1`。`package.json` が唯一の元で、PC 版と Android 版の versionName / versionCode もここから作ります。

| 番号 | 増やす基準 | 例・コマンド |
|---|---|---|
| x | 新しい用途や、まとまった機能が加わる | 同期、新しいノート形式、グラフビュー。`npm run version:minor`（1.0.2 → 1.1.0）。y は 0 に戻す |
| y | 既存機能の修正・改善。小さな操作機能の追加も含む | 不具合修正、配置変更、誤操作防止、コピー操作の改善。`npm run version:patch`（1.0.1 → 1.0.2） |

新しいボタンを追加したという理由だけで x を増やしません。「新しくこれができるようになった」と一つの機能として紹介できる変更を x の対象とします。迷う程度の小さな改善は y とします。今回のID操作・複数選択の改善は `1.0.1` とし、先に付けた `1.1.0` は番号の訂正として扱います。

バージョンを上げるのは、利用者向けの更新をまとめてコミットする前に 1 回。README だけの変更では上げません。

**リリースの作り方**: 変更の内容に応じて `npm run version:patch` または `npm run version:minor` を実行します。確定したバージョンでタグを付けます（例: バージョンが1.0.2なら `git tag v1.0.2 && git push --tags`）。GitHub Actions が Windows / Mac / Linux のインストーラーを作り、リリースに置きます（`.github/workflows/release.yml`）。

## 画面
- 左のタブ: **デジタル** / **紙** / **Index**（グローバルIndex）。検索結果はまとめて出る
- 検索の順: **Index（キーワード）→ トピックIndex → ノート**
- タブ（Obsidian 風）: クリックで今のタブ、**Ctrl+クリック／中クリックで新しいタブ**。Ctrl+W 閉じる・Ctrl+T 新しいタブ・Ctrl+Tab 次へ。次の起動でも残る
- ノートの上: `並列`（1a→1b）`分岐`（1a→1a1）
- `＋キーワード` で索引を足す（× で外す）。**読み**の候補が自動で入る（違えば直す）。Index は読みのあいうえお順で、行（あ・か・さ…）ごと。検索は読みでも当たる。`＋トピックIndex` で索引を探して選び、キーワードを入れて追加（同じキーワードの行があればそこに足す）。そこから新しく作る（このノートが入口）こともできる
- 左の一覧のノートを、トピックIndex の編集欄へドラッグすると ID が入る
- デジタルは作った日時（`2026-10-10 11:12`、変えられない）。紙は日付なし、画像の横に「テキスト化」を書く
- 📷 スキャン取り込み: 1枚ずつ紙のIDを付ける（Enter 決定、Tab 前のID）

## リンク（書くとその場でリンクになり、クリックで飛ぶ）
| 書き方 | 意味 |
|---|---|
| `:1a` | 1a へ続く |
| `1a:` | 1a 全体 |
| `1a(1)` `:1a(1)` `1a(1):` | 1a の (1) の位置へ |
| `(1)` | 引用の目印（赤くなるだけ） |
| `(1):` `:(1)` | 同じノートの (1) の位置へ |

デジタルのリンクはデジタルへ、紙の中のリンクは紙へ（ID は別々）。

## 赤い点（グローバル Index の「編集」）
左の Index タブの上の「編集」を押すと、キーワードごとの ID が選べるようになります。点を付けたい ID を押すと、その ID の上に赤い点が付き、押すとそのトピックIndex が開きます（もう一度押すと外れる）。その ID にトピックIndex が無ければ、確認のうえ新しく作ります。

## 0 Index
左のIndexタブの隣の **0** から、親ID（`1`、`2`、`3`…）のトピックIndexを番号順に開けます。デジタル・紙の両方を表示し、`1a` など分岐先の索引は含めません。既存の索引を自動的に一覧するので、新しく作成・登録する操作は不要です。

## トピックIndex の書き方
- `キーワード ID ID …` の1行ずつ。ID の前に `*` を付けると、そのIDの上に赤い点（例: `PKM *1 1a`）。グローバルな Index でも同じ印で表示されます。
- `+GUI` のように `+` で始めると、別のトピックIndexへの案内（星マーク。`★` も同じ）。
- Index（左の一覧）やトピックの中の ID を押すと、そのIDにトピックIndexがあれば、最初からそちらが開きます（ノート本体は、トピックの上の入口から）。

## トピックIndex
入口は1つ（1つのIDに1つの索引）。ノートの「＋トピックIndex」から作る。「入口・名前」で入口と名前を変える・削除する。
1行に `キーワード ID ID …`（ID がリンクになる）。`★ 名前` で別のトピックIndexへ。
編集はデジタル欄と紙欄に分けて書き、表示はキーワードごとにまとめる。Index には出さない。

## キーワードをまとめる（赤い点）
同じキーワード（例: GUI）が、PKM の話にもプログラミングの話にも出てくるとき、**それらをまとめる上位の文脈**があるなら、そのトピックIndex を作る。無ければ、新しい ID でその上位のノートを作って入口にする。
- Index タブで、ID が2つ以上あるキーワードに「📑 作る」が出る。押すと、入口（新しいノート／既存のノート）と名前を決めて作れる。キーワードの ID（デジタルも紙も）が最初から入る
- 紙と同じく、`GUI 1 2 3` の **ID のうち1つの真上に赤い点 ●** を付ける（アプリの Index と `Index.md`）。その ID がこのキーワードの索引の入口で、点を押すとトピックIndex へ飛ぶ。1つのキーワードに1つだけ
- 入口は、そのキーワードの ID の中から選ぶか、新しい ID を作る。入口のノートにはそのキーワードが自動で付き、`GUI 1 2 3 4` のように並びに入る
- 点は後から指定し直せる。トピックIndex の「入口・名前」で、入口の ID と点のキーワード（空にすると外れる）を変える
- Index タブの「＋ トピックIndexを新しく作る」は、キーワードなしで単独に作る（入口は新しいノートか既存のノート）

## 保存（全部が1つのフォルダ。Brave の Markdown Viewer でも全部たどれる）

- 入力内容は自動保存します。画面上部に「保存中…」「保存済み」「保存エラー」を表示し、エラー時は入力を保持して再試行します。ノートを切り替えても保存待ち・保存中の処理を保持し、終了時は保存の成功を確認してから閉じます。
- ノート・日記・トピックIndex・チャットメモには、保存が完了するまで端末内にも復元用の控えを残します。途中でアプリが停止した場合、同じ保存先を開くと未保存の入力を復元します。この控えは端末内のため、別のPCへ移すときは「保存済み」を確認してください。
- ノート右側の「トピック」の＋で開く画面では、検索欄の右の「＋」を押して名前を入力すると、そのノートを親にしたトピックIndexを追加できます。
- ノート右パネルの表示順は「キーワード → 自トピック → トピック → 親 → 子 → バックリンク」です。

保存先は普通のフォルダ（初めて起動したとき、画面で選びます（既存の vault を開く／新しく作る。標準は `~/YuriiNote`）。右上 📁 で変更）。**サブフォルダは作らず、全部を平らに置く**（消したものを入れる `.trash` だけ例外）。**`Index.md` を開けばリンクだけで全部に届く。**
- `D_<ID>.md` … デジタルのノート（日付・キーワード・本文）
- `P_<ID>.md` と `P_<ID>.jpg` … 紙のノートとスキャン画像
- `T_<名前>.md` … トピックIndex
- `Index.md` … キーワード → ID（読みのあいうえお順、行ごと。読みもここに保存）
- `デジタル.md` / `紙.md` … 先頭の ID のリンクだけ
- 添付は元の名前のまま同じフォルダ
- 各ノート: 上に日付・索引（小さく）、下に ← 前・↑ 上・分岐・次 →・トピックIndex。リンクはすべて同じフォルダの中
- アプリで書いた `:1a` などはファイルでは本物のリンク（`[:1a](D_1a.md)`）になり、読み込むと元に戻る
- 前の版の置き方（`digital/` `paper/` `topic/` `files/`、直下の `<ID>.md`）は、次に起動したときに自動で平らな形に移し、本文の添付リンクも書き換える

## グラフ（左の 🕸）
ノートを丸、番号の親子を灰の線、`:ID` のリンクを青い矢印、2つ以上のノートに付いたキーワードを赤い点で描きます。位置は計算して固定（開き直しても同じ）。ドラッグで動かし、ホイールで拡大・縮小、丸を押すとそのノートを開きます（Ctrl+クリックで新しいタブ）。
検索欄に `folgezettel:1` と入力すると `1` とその子孫（例: `1a`、`1a1`）を表示し、`10` などの別系統は除外します。`folgezettel:d:1` / `folgezettel:p:1` でデジタル / 紙に限定できます。ツリーマップでは番号の親子の線も表示します。

## 紙のIndexの並べ替え（左の 🗂）
キーワード・よみ・ID（まだ取り込んでいない紙のIDでもよい）を書くと、並び順のどこに入るかが見えます。紙のノートができると本 Index に自動でマージされます。

## 左の一覧とタイトル
- ノートには**タイトル**を付けられる（ノートの上の欄。任意）。左の一覧は「**タイトル**、その下に小さく ID（IDなしは日時）とキーワード」。タイトルが無ければ本文の最初の行を出す
- **トピックIndex**も一覧に出る。「トピックIndex」の印つきで、**入口のノートの手前**に並ぶ（`1-PKM` はノート 1 の上）。入口がないものはデジタルの先頭

## ノートを作る（IDなし → あとで整理）
「＋ 新規」から選ぶ: **ノート（IDなし）**／ノート（IDを付けて作る）／🎭 なりきりチャット／🗺 キャンバス。
- **IDなし**のノートは、とりあえず書く場所。`D_u20261107-143521.md` のように日時の名前で保存され、左の「**未整理**」に並ぶ。日記の「今日のノート」にも載る（日時のリンク）
- あとから「**IDを付ける**」: ID を直接／親のノートにぶら下げる（分岐）／となりに並べる（並列）。付けると名前が変わり、日記のリンクは `:ID` に直る。ID を付けると、キーワードやトピックIndex、Index にも出せる
- **IDの表示・コピー**: ノート上部のIDは入力欄ではなく、クリックするとIDだけをコピーします。横のコピーボタンはありません。変更・解除はノートの「⋯」→「IDを変更・解除…」から開く設定画面で行います。空欄ではIDは外れません。
- **IDをいったん外して再指定**: ID設定画面の「IDを外す（IDなしにする）」を押し、確認後にIDなしへ戻せます。「IDを付ける」ボタンから再指定できます。既存の参照はファイルリンクに変更し、旧IDはトピックIndexなどから外されます。子のIDと本文は変更しません。
- 3種類（文章・なりきりチャット・キャンバス）は、どれも同じノート。一覧にはアイコンで区別される
- 左のアイコン列は **ノート / 日記 / チャットメモ**

## 日記と記録（左の縦のアイコン列 📔）
- ファイルは**日時の名前**（`20261108050000.md`）。先頭の YAML に `record`（種類。日記・夢など）・`date`（日付）・`parent_record`（その日の上位）・`title`。昔の `D_日付.md` は、初回に自動で直ります（バックアップを取ってから）。日付が変わるのは**朝5時**。
- 上に**種類のタブ**（日記・夢・ビジネス…）。「＋ ⚙」で、種類を**足す・上位を決める・名前を変える（その種類の日のノートも一括）・まとめる（表記揺れの統合。同じ日は時刻の順にまざる）・消す**。「日記」自身は、名前の変更も削除もできません。
- 「今日の○○」と、日付を選んで過去の日を開く（無ければ作る）。一覧は **年・月・日の階層**（月はいつも、年は2つ以上の年にまたがってから）。
- **上位・下位（DailyNotes）**: 日ごとに上位を持ちます（その日のノートの上の欄で変えられる）。種類の上位を変えても、もう作った日は変わらず、これから作る日だけ新しい上位になります。上位のノートの上に、その日の下位への**リンク（DailyNotes）**が並びます（日記には最上位の記録だけ、各記録にはその日にある直接の下位だけ。その日に無い中間は飛ばします）。
- **その日に作ったデジタルノートのリンク**は、「日記」の「## 今日のノート」の節だけに自動で入ります（無いノートへのリンクは出しません）。
- **紙の日記**: スキャン取り込みの画面で日付を入れて「日記として登録」（Alt+D）。「日記」だけ。ID は付けず、その日の日記の最後の「## 紙の日記」に画像が入ります。
- 検索の結果に日記・記録も出ます。Brave でも `日記.md` から種類ごとに年月日をたどれます。

## チャットメモ（apk 風。左の 💬）
開くとすぐ書ける。Enter で送る（Shift+Enter で改行）。📎・ドラッグ・貼り付けで画像やファイルも付けられる。
- **トピック**: 「全部表示」「トピック未選択」「日記」と、自分で作るトピック。トピックの型を選ぶ
  - **吹き出し型** … 1件ごとに別のノートになる予定の吹き出し。**あとからIDを指定する**までは、チャットに並ぶだけ（取り込む手間はなく、`C_チャット.json` に入っている）
  - **全体型** … トピック全体が1つのデジタルノート。吹き出しは空行で区切った段落。時刻（`HH:MM`）を付けるかは設定でオン/オフ
  - **日記** … 書いたものは、今日の日記の本文に `HH:MM 本文` で入る
  - 「全部表示」で書いたものは「トピック未選択」に入る
- **吹き出しの右クリック**: 続けて書く（親子。字下げして並ぶ）／文脈につなぐ（別の吹き出しを押してつなぐ）／**IDを指定してノートにする**／書き直す／トピックを変える／コピー／消す
- **ノートにする**: 「このノートのID」か「親のノートのID（分岐として付ける）」を指定。**続けて書いた子の吹き出しも一緒に**、並列・分岐のIDでノートになり、チャットから消える。ノートの作成日は吹き出しを書いた日時（その日の日記に載る）。文脈でつないだ相手が先にノートになっていれば、`:ID` のリンクが入る
- 消した吹き出しは `C_チャット.json` の `trash` に残る
- **表示**: 吹き出しは全部右寄せ。字下げはせず、全部同じ位置に並べます。上の「時系列」「folgezettel」で切り替え（folgezettel は分岐の番号順: 1, 1a, 1a1, 1b, 2 …。番号は吹き出しの上に出ます）。
- **分岐・文脈**: 吹き出しを右クリック →「分岐」（その続きを書く）／「文脈」（つなぎたい相手の吹き出しを押す。何個でも持てる）。吹き出しを**クリック**すると、その下に 分岐元・分岐・文脈 が開き、押すとその発言に飛びます。
- **ノートにするとき**: 文脈でつないだ相手が、もうノートなら、その ID（`:1a` の形）がノートの**先頭**に入り、空行をはさんで本文が続きます。

## なりきりチャット（ノートの一種）
一人二役のチャット。Q&A・議論・相談などに使える。**ふつうのノート**（ID もつく・一覧に並ぶ・`:1a` でリンクできる）で、開くとチャットの画面になる。「＋ 新規」→「🎭 なりきりチャット」で作る。会話のデータはそのノートの中に入り、本文には発言の文字が作られる（検索に出る）。
- **役**: 名前と、アイコン（絵文字か画像。決めなければ頭文字の丸）。「役の一覧」で作る・直す・消す。保存した役はどの会話にも**何人でも呼び出せる**（`K_roles.json`）。会話の「＋ 役」で足し、「役の一覧」で直す
- **話す役の切り替え**: 入力欄の上の役を押す、または **Tab**（Shift+Tab で逆）。Enter で送る。先頭の役が右、ほかは左
- **引用**:
  - 「❝ 引用」で、**ノートを吹き出しとして**（中身が出て、押すとそのノートへ）、または**ほかのなりきりチャットの発言**を引用して送る
  - 発言の右クリック →「**ノートに引用する**」で、ノートの末尾に `> **名前**: 発言` と元の会話（ノート）へのリンクが入る。そのリンクを押すと、会話のその発言へ飛ぶ
- 発言の右クリック: 書き直す／ノートに引用／コピー／消す。画像・ファイルの添付も可
- **左右**: いま話す役（送るときに選んでいる役）の発言が右、ほかの役が左に出ます。役を切り替える（Tab）と、左右が入れ替わります。
- **返信**: 発言の「↩」（右クリックの「返信する」でも）で、その発言に返信します。送った発言の上に、相手の発言の抜粋が付き、押すと元の発言に飛びます。自分の発言にも返信できます。
- **指名**: 入力欄に `@` と打つと、会話の役の候補が出ます（Tab / Enter / クリックで決める）。発言の中の `@役名` は青く目立ちます。

## キャンバス（ノートの一種）
何もないところを**1回クリック**すると、そこに文字の箱ができて、すぐ書けます（Esc か、ほかをクリックで確定。空の箱は消えます）。箱は文字の大きさにぴったり合います。つなぐときは、箱を選んで **「↗ 線」** → 相手の箱をクリック。線をダブルクリックでラベル、Delete で消す（確認あり）。ノートの引用・画像の箱も置けます。ドラッグで動かし、Ctrl+ホイールで拡大縮小。

## 編集（Obsidian 風）
見出し・**太字**・*斜体*・`コード`・チェックボックス（押して切り替え、Ctrl+Enter）・箇条書き（Enter で続け、Tab / Shift+Tab で字下げ、Alt+↑↓ で子ごと並べ替え、▾ で折りたたみ）・表（カーソルが外にあると整形表示。「▦ 表」で入れる）。ふつうの行の Tab は Tab 文字。最後の行より下をクリックすると、最後にカーソルが行く。

## 添付（リンクとして本文に入る）
ノートの「📎 添付」で選ぶ、ノートにファイルを**ドラッグ＆ドロップ**、または**貼り付け**（スクリーンショットなど）。ファイルは保存フォルダに**そのままの名前でコピー**され、**本文のカーソル位置にリンクが入る**。
- 画像は `![](名前.png)`（説明文は空）。本文の中に**普通に表示**される（押しても何も起きない）。ファイル名のうち空白や `( )` などだけ `%20` `%28` `%29` に置き換わり、日本語はそのまま
- ほかのファイル（PDF・HTML・CSV など）は `[名前.csv](名前.csv)`。押すと **OS の既定のビューアー**で開く。`https://…` のリンクは既定のブラウザで開く
- カーソルが外にあるときは名前だけが見え、カーソルを置くと元の記述が出る。消したいときはその行を消す（ファイルは残る）
- 標準の Markdown なので、Brave の Markdown Viewer でも画像が見え、リンクで開ける
- 同じ名前があれば `-1`、`D_` `P_` `T_` で始まる名前や `Index.md` などとぶつかるときは先頭に `F_` が付く

## エクスポート（仮の出力。ファイルは作りません）
左の一覧の「☑ 選択」でノートを選び（検索結果の「全部」でもよい）、**📤 エクスポート**。開いた画面で、足したり外したりして、件数と一覧を確認します。
- **関連を足す**: リンク先／リンク元／同じキーワード／同じトピックIndex（チェックして「足す」）
- **番号の範囲**: `1a 〜 1a5` の範囲、または `1a` の枝（子孫すべて）
- 「一時タブで確認」で、1つの Markdown が出ます（保存はされず、タブを閉じると消える）。「コピー」で貼り付け用に。
- ノートは番号順。リンクは、選んだノートの中を指すものだけ生かし、外へのリンクは普通の文字（`:3` → `3`）にします。

## スマホ（USB で取り込む）
同期は、いったんやめました（あとで足します）。スマホのアプリは、**メモを書くだけ**の Gnosis 風の画面です。通信はしません。
- **アプリ**（`android/`・Kotlin）: トピックごとのチャットメモ、分岐・文脈、アラーム（何分おき・何時から何時まで・通知から日記）、紙のスキャン（Google の文書スキャナー。番号を付ける／写真だけ撮る／あとから名前を付ける）。
- **入れる**: スマホを USB でつなぎ（USB デバッグをオン）、YuriiNote の「⋯」→**「スマホにアプリを入れる…（USB）」**。PC に `adb` が要ります。
- **取り込む**: 同じく「⋯」→**「スマホのメモを取り込む…（USB）」**（adb でアプリの中のデータを直接読みます）。メモは「未整理」（IDなし）のノートに。写真は日時の名前で「ファイル」に。**日記**のトピックは、その日の日記に時刻つきで。**時系列記録**のトピック（夢など）は、その種類のその日のノートに（無ければ種類を足します）。**1 つのノートにまとめる**トピックは、そのノートに追記。番号つきのスキャンは、その番号の紙のノートの画像に（番号の無いものは、スマホで番号を付けてから）。
- **スマホから消す**: 取り込んだメモには、スマホに「取り込み済み」と出て、そのメモだけ、スマホの中から消せます（PC のノートは消えません。まだ取り込んでいないメモは消せません）。
- 取り込み先は、vault の `.pkm-import.json` に覚えます（同じメモは二度取り込みません）。
- 作り直す（JDK 17 と Android SDK が要ります）: `sh android/build-apk.sh` → `downloads/YuriiNote-memo.apk`。

## 削除
ノートの「削除」、または左上の「☑ 選択」で複数選んで一括削除（Shift+クリックで範囲）。ファイルは `.trash` に移り、索引の行からもIDが外れる（入口だった索引は入口なしになる）。
複数選択中は、上段に件数と「やめる（Esc）」、下段に「全部」「コピー」「似たノート」「エクスポート」「削除」を表示します。ボタンはサイドバーの幅に合わせて折り返します。「コピー」は選んだノートのタイトルと本文をMarkdownとしてコピーし、「やめる」またはEscで選択を終了します。ダイアログを開いている間のEscは、そのダイアログを先に閉じます。
